      📖 Como usar o Medusa
      
    

    

      
O Medusa é um construtor de consultas a APIs. Tudo roda no seu navegador — nada é enviado a servidores do Olimpus. As consultas ficam salvas localmente.


      
1 Montar a requisição aba Requisição

        Defina método e URL. Adicione headers e query params (use o ✓ para ligar/desligar cada um) e o payload (JSON, raw ou sem corpo). Em qualquer campo, escreva {param} onde quiser injetar valores dos workers.
      


      
2 Auto-config aba Auto-config

        Cole e clique Auto-configurar. Detecta automaticamente 4 formatos: cURL, fetch(), cabeçalho bruto (Chave: Valor) e o painel "Cabeçalhos" do DevTools (formato em duas linhas, com :authority/:path). Preenche método, URL, headers e body para você.
      


      
3 Importar de um HAR aba HAR

        No navegador: DevTools → Network → Export HAR. Arraste o .har na aba HAR. O Medusa lista todas as requisições e identifica as APIs (XHR/fetch, JSON/XML, rotas /api, /v1, GraphQL…). Filtre, marque Somente APIs, clique Usar para carregar uma na requisição, ou selecione várias e mande para os Workers / exporte as URLs.
      


      
4 Workers e parâmetros aba Workers

        Coloque a lista de parâmetros (um por linha) — cada linha vira uma requisição com {param} substituído. Defina quantos workers rodam em paralelo (1–50) e um atraso entre lotes se a API tiver limite. Para múltiplos campos, use uma linha JSON por item, ex.: {"id":1,"uf":"SP"}, e injete {id}, {uf}. O token padrão é param, mas pode trocar.
      


      
5 Executar e tratar o retorno aba Resultado

        Clique Executar consulta. Veja o JSON original ou em Tabela. Erros da API aparecem em destaque, por requisição. Baixe o resultado em Excel (colunas ordenadas conforme os campos do JSON, objetos aninhados achatados como a.b), CSV ou JSON.
      


      
6 Salvar, clonar, exportar

        Salvar guarda a consulta na barra lateral (no navegador). Clonar duplica. Exportar/Importar trocam a config como arquivo .medusa.json. Salvar em pasta local grava no diretório que você escolher (navegadores Chromium).
      


      

        ⚠ CORS: por ser uma página no navegador, APIs que não liberam CORS bloquearão a chamada (aparece na lista de erros). Headers como Origin, Referer, User-Agent e Cookie são gerenciados pelo navegador e não podem ser definidos por script — são ignorados silenciosamente.
